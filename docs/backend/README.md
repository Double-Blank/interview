# 后端面试题

Java 后端题库，按模块拆开。先把 P0 吃透，再看 JVM、并发和 AI 衔接。

## 复习优先级

结合你的简历，我不建议平均分配时间。前端转 AI 全栈，Java 更重要的是证明你能独立完成后端业务开发，而不是背诵 JVM 的所有底层细节。

| 优先级 | 模块 | 掌握要求 |
|--------|--------|--------|
| (P0) | Java 基础、集合、Stream | 熟练掌握 |
| (P0) | Spring Boot、Spring MVC | 熟练掌握 |
| (P0) | MyBatis、CRUD、分页 | 能独立开发 |
| (P0) | RESTful API、参数校验 | 能独立设计 |
| (P1) | JVM、线程、并发 | 理解常见原理 |
| (P1) | Maven、事务 | 能解决常见问题 |
| (P2) | AI 后端、SSE、RAG | 结合项目实践 |

## 推荐复习方式

不要把这 250 多道题全部当作背诵题。

可以按以下方式整理：

- **第一遍：** 每道题尝试口述，标记不会的题。
- **第二遍：** 查资料，自己整理答案，尽量用代码验证。
- **第三遍：** 不看笔记，模拟面试官追问。
- **第四遍：** 把知识点映射到自己的项目中。

**我的建议：** 先把 P0 部分吃透，再学习 P1。尤其是 Spring Boot 请求处理流程、依赖注入、MyBatis 数据访问、事务、参数校验，这些知识点最容易和你的 Next.js / NestJS 项目形成对照。

后续可以直接按这套题库逐章进行模拟面试，我来扮演面试官，一次问一道题，根据你的回答继续追问。
